# Requisitos funcionales

Lo que el sistema **debe hacer**. Cada requisito tiene un ID para poder referenciarlo
en Issues, commits y pruebas.

| ID | Requisito | Actor | Prioridad | Estado |
|----|-----------|-------|-----------|--------|
| RF01 | Mostrar un catálogo/calendario interactivo con los eventos próximos (talleres, foros, pláticas). | Estudiante | Alta | Pendiente |
| RF02 | Permitir al administrador crear, publicar y editar avisos o eventos. | Administrador | Alta | Pendiente |
| RF03 | Mostrar un directorio con contactos y horarios de atención de orientación y psicología de la Facultad, y números de ayuda (Línea de la Vida nacional, Línea Amiga local). | Estudiante | Alta | Pendiente |
| RF04 | Mostrar un apartado de información fija (folletos, contenido audiovisual) sobre salud mental. | Estudiante | Media | Pendiente |
| RF05 | Mostrar una fotogalería que documente las actividades publicadas como evidencia de la participación estudiantil. | Estudiante / Administrador | Media | Pendiente |
| RF06 | Incluir un módulo de orientación vocacional con guías de carrera y contactos de apoyo (tutorías). | Estudiante | Media | Pendiente |

> Prioridad: Alta / Media / Baja. Estado: Pendiente / En progreso / Hecho.
