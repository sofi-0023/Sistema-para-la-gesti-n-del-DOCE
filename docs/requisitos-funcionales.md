# Requisitos funcionales

Cada requisito cuenta con un ID estructurado por módulos para facilitar su trazabilidad en Issues, commits y pruebas.

| ID | Módulo | Rol | Descripción |
| :--- | :--- | :--- | :--- |
| **RF-CALENDARIO-01** | Calendario | Estudiante / Visitante | El sistema mostrará un catálogo/calendario interactivo con los próximos eventos, permitiendo a los usuarios consultar la información correspondiente a cada actividad disponible. |
| **RF-CALENDARIO-02** | Calendario | Estudiante / Visitante | El sistema deberá permitir al usuario seleccionar una actividad y visualizar su nombre, descripción, fecha, hora, lugar o modalidad, y persona u organización que la imparte. |
| **RF-CALENDARIO-03** | Calendario | Administrador | El sistema deberá permitir al administrador crear y publicar actividades y avisos para que los usuarios puedan consultarlos. |
| **RF-CALENDARIO-04** | Calendario | Administrador | El sistema deberá permitir al administrador editar y retirar o cancelar actividades y avisos ya publicados. |
| **RF-DIRECTORIO-01** | Directorio | Estudiante / Visitante | El sistema deberá permitir a los usuarios consultar los contactos y horarios de atención del departamento de orientación y psicología de la Facultad de Matemáticas. |
| **RF-DIRECTORIO-02** | Directorio | Estudiante / Visitante | El sistema deberá permitir a los usuarios consultar las líneas de ayuda disponibles (Línea de la Vida nacional y Línea Amiga local). |
| **RF-INF-01** | Contenido | Estudiante / Visitante | El sistema deberá permitir a los usuarios consultar material informativo sobre salud mental (folletos, videos y documentos). |
| **RF-INF-02** | Contenido | Administrador | El sistema deberá permitir al administrador agregar, actualizar y retirar material informativo. |
| **RF-INF-03** | Contenido | Estudiante / Visitante | El sistema permitirá a los usuarios consultar una fotogalería con imágenes correspondientes a las actividades de salud mental realizadas en la Facultad de Matemáticas. |
| **RF-VOC-01** | Vocacional | Estudiante / Visitante | El sistema deberá permitir a los usuarios consultar los contactos de apoyo (tutorías) y guías de carrera. |
| **RF-AUT-01** | Seguridad | Administrador | El sistema deberá permitir al administrador iniciar y cerrar sesión para acceder a las funciones de gestión de contenido. |
