# RF04 - Editar/retirar

## Requisito funcional 

El sistema deberá permitir al administrador editar y retirar o cancelar actividades y avisos ya publicados.

## Historia de usuario

Como administrador del sistema,
Quiero modificar los datos de una actividad o marcarla como cancelada/retirada,
Para actualizar información errónea o notificar cambios de último momento.
