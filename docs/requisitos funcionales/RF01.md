# RF01 - Catálogo/calendario

## Requisito funcional 

El sistema mostrará un catálogo/calendario interactivo con los próximos eventos, permitiendo a los usuarios consultar la información correspondiente a cada actividad disponible.

## Historia de usuario

Como usuario del sistema puedo visualizar el calendario o interfaz interactiva donde estan señaladas los próximos eventos y actividades, de igual forma revisar y si el usuario lo desea agendar una actividad ofertada por la facultad para el bienestar de la salud mental
