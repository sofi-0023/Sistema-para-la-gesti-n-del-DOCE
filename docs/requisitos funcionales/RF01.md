# RF01 - Catálogo/calendario

## Requisito funcional 

El sistema mostrará un catálogo/calendario interactivo con los próximos eventos, permitiendo a los usuarios consultar la información correspondiente a cada actividad disponible.

## Historia de usuario

Como usuario del sistema puedo visualizar el calendario o interfaz interactiva donde estan señaladas los próximos eventos y actividades, de igual forma revisar y si el usuario lo desea agendar una actividad ofertada por la facultad para el bienestar de la salud mental

# RF02 - Detalle de actividad

## Requisito funcional

El sistema permitirá al usuario seleccionar una actividad para visualizar su información detallada, la cual incluirá:
* **Nombre de la actividad**
* **Descripción**
* **Fecha y hora**
* **Modalidad** (presencial, virtual, híbrida)
* **Lugar / Enlace**
* **Institución u organizador** que imparte la actividad

## Historia de usuario

**Como** estudiante o usuario del sistema,  
**Quiero** seleccionar una actividad del calendario para ver su detalle completo (nombre, descripción, fecha, hora, lugar/modalidad y la institución organizadora),  
**Para** evaluar si puedo y deseo asistir a la actividad.
