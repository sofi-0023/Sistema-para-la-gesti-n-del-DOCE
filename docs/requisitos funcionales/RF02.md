# RF02 - Detalle de actividad

## Requisito funcional 

El sistema deberá permitir al usuario seleccionar una actividad y visualizar su nombre, descripción, fecha, hora, lugar o modalidad, y persona u organización que la imparte.

## Historia de usuario

Como estudiante o usuario del sistema,
Quiero seleccionar una actividad del calendario para ver su detalle completo (nombre, descripción, fecha, hora, lugar/modalidad y el organizador que impartira la actividad),
Para evaluar si puedo y deseo asistir a la actividad.
