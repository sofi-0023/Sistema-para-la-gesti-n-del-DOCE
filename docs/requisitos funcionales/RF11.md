# RF11 - Inicio/cierre de sesión

## Requisito funcional 

El sistema deberá permitir al administrador iniciar y cerrar sesión para acceder a las funciones de gestión de contenido.

## Historia de usuario

Como administrador del sistema,
Quiero iniciar y cerrar sesión mediante mis credenciales autorizadas,
Para acceder a las funciones de gestión de contenido y resguardar la seguridad del sitio.
